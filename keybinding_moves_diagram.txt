medit movement and shift-movement reference
Source: config/medit/keybindings.json

Normal / Visual movement cluster

                +-------------------+      +--------------------+
                |   Up / k          |      |  Shift-Up / K      |
                |   move_up         |      |  visual_move_up    |
                +-------------------+      +--------------------+

+-------------------+  +--------------------+  +-------------------+  +--------------------+
| Left / h          |  | Shift-Left / H     |  | Right / l         |  | Shift-Right / L    |
| move_left         |  | visual_move_left   |  | move_right        |  | visual_move_right  |
+-------------------+  +--------------------+  +-------------------+  +--------------------+

                +-------------------+      +--------------------+
                | Down / j          |      | Shift-Down / J     |
                | move_down         |      | visual_move_down   |
                +-------------------+      +--------------------+
